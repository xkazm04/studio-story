### EXPORT-03 Gap Detail

**Requirement:** "Visual novel output — branching narrative exported as navigable, illustrated, voiced experience"

**Phase verification said "passed"** because `VisualNovelGenerator` fully supports branching choices, background images, dialogue audio, endings, and JS state machine — verified with 10 unit tests.

**Integration gap:** The bridge function `exportToVisualNovel()` in `src/lib/export/index.ts` (lines 423-452) only populates `id`, `name`, and `content` on each `StoryExportScene`. It does not pass through:
- `choices` (from scene-choices API)
- `dialogueLines` (from screenplay parser)
- `imageUrl` (from illustration pipeline)
- `narrationUrl` (from TTS pipeline)

The `ScriptData` interface lacks fields for these. Result: Visual novel export produces a linear reader, not the branching interactive the requirement describes.
