    1. Update `src/agents/useAdvisorVoice.ts`:

       **Add auto-connect logic:**
       - Add a `pendingRecordAfterConnect` ref (boolean). When `startRecording` is called and `voiceConnectionState === 'disconnected'`, set `pendingRecordAfterConnect = true` and call `connectVoice()`. In the `onSetupComplete` handler (when connection succeeds), if `pendingRecordAfterConnect` is true, call `startRecording()` and reset the flag.
       - This removes the requirement for users to explicitly connect before using voice.

       **Add idle disconnect:**
       - Add `IDLE_DISCONNECT_MS = 2 * 60 * 1000` constant (2 minutes).
       - Add `idleTimerRef` using useRef.
       - When `stopRecording` is called, start an idle timer. If no `startRecording` call happens within `IDLE_DISCONNECT_MS`, call `disconnectVoice()`.
       - When `startRecording` is called, clear any existing idle timer.
       - This prevents continuous WebSocket drain per research pitfall #4.

       **Add push-to-talk keyboard handler:**
       - Add a `usePushToTalk` section within the hook (or as a separate internal effect).
       - Register keydown/keyup listeners on `document`:
         - `keydown`: If `e.code === 'Space'` AND `e.repeat === false` AND `!isTypingInInput(e)`, call `e.preventDefault()` and `startRecording()`.
         - `keyup`: If `e.code === 'Space'` AND `isRecording`, call `stopRecording()`.
       - `isTypingInInput(e: KeyboardEvent): boolean` checks if `e.target` is an HTMLInputElement, HTMLTextAreaElement, or has `contenteditable` attribute. Also check for `[role="textbox"]` and `[data-lexical-editor]` (for TipTap/Lexical editors).
       - Return value: expose `pushToTalkEnabled` state (boolean, default true) and `setPushToTalkEnabled` setter so users can disable push-to-talk.

       **Wire inputTranscription to multimodal input:**
       - Accept an optional `onTranscription?: (text: string) => void` callback parameter on the hook.
       - When connecting the GeminiLiveClient, wire `liveClient.onInputTranscription((text) => { onTranscription?.(text); })`.
       - This allows the caller (AdvisorOverlay or parent component) to bridge transcriptions to `useMultimodalInput.handleTranscription`.

       **New return values** (add to existing):
       ```typescript
       pushToTalkEnabled: boolean;
       setPushToTalkEnabled: (enabled: boolean) => void;
       liveClientRef: React.RefObject<GeminiLiveClient | null>; // expose for useMultimodalInput
       ```
