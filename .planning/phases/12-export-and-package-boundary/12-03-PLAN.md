         - `showEnding()`: display "The End" overlay with story title
         - Click/tap anywhere on dialogue box calls advance() (classic VN click-to-advance)
         - Keyboard: Space/Enter = advance, number keys 1-9 = select choice
       - Export `generateVNHTML(title: string, css: string, bodyHTML: string, engineJS: string): string` -- complete HTML document

       - Class with async `generate(data: StoryExportData): Promise<ExportResult>`
       - Transform StoryExportScene[] into VNSceneData[] (flatten dialogueLines into sequential lines with speaker/text/audioUrl, map choices with targetSceneId to targetIndex)
       - For scenes without dialogueLines: create a single narration line from scene content
       - Fetch and encode images/audio as base64 data URLs (same pattern as HTML5BundleGenerator -- inline helper or import)
       - For dead-end detection: scenes with no choices and isEnding !== true get auto "The End"
       - Assemble: generateVNCss, build body HTML (minimal -- just container divs for background, dialogue box, speaker, text, choices, ending overlay), generateVNEngine, generateVNHTML
       - Return ExportResult with format 'visual-novel', blob 'text/html;charset=utf-8'
