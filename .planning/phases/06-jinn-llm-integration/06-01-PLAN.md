<objective>
Create the headless LLM transport layer in @dzin/core that bridges the IntentBus needs-llm results to an external LLM via a pluggable sendToLLM callback.

Purpose: JINT-03 requires Claude CLI integration. This plan builds the engine-side transport contract (types, serialization, retry logic, status tracking) that Phase 6 Plan 02 will wire to the actual persistent CLI session. Keeping the transport headless and callback-based maintains @dzin/core's domain-independence.

Output: `createLLMTransport()` factory, `serializeForClaude()` serializer, full type definitions, and tests.
