  <name>Task 1: Ambient observer and workflow patterns with tests</name>
  <files>src/agents/ambient-observer.ts, src/agents/workflow-patterns.ts, src/agents/__tests__/ambient-observer.test.ts</files>
  <behavior>
    - createAmbientObserver subscribes to IntentBus events and matches against patterns
    - entity-created trigger fires when an intent with action matching entityType completes
    - idle trigger fires when no events occur for afterMs and condition returns true
    - sequence trigger fires when matching events occur within withinMs window
    - Matched pattern emits a suggestion via onSuggestion callback
    - Same pattern cannot fire again within its cooldownMs (default 300000 = 5min)
    - Max 2 active suggestions at once; new suggestions queue
    - dismiss(suggestionId) removes a suggestion and decrements active count
    - destroy() unsubscribes from IntentBus and clears all timers
    - DEFAULT_PATTERNS includes 4 patterns: character-created, scene-opened, story-setup-complete, idle-empty-workspace
  </behavior>
  <action>
Create `src/agents/workflow-patterns.ts`:
- Types: `PatternTrigger` (union of `{ type: 'entity-created'; entityType: string }`, `{ type: 'idle'; afterMs: number; condition: (panels: string[]) => boolean }`, `{ type: 'sequence'; events: Array<{ intentType: IntentType; action: string }>; withinMs: number }`)
- Type: `SuggestionTemplate`: `{ id: string; text: string; intentToDispatch: { type: IntentType; payload: unknown } }`
- Type: `WorkflowPattern`: `{ id: string; name: string; trigger: PatternTrigger; suggestion: SuggestionTemplate; cooldownMs: number }`
- `DEFAULT_PATTERNS`: Array of 4 WorkflowPatterns:
  1. `character-created`: entity-created trigger for 'compose'/'open' on character panels -> suggest "Add character traits and backstory"
  2. `scene-opened`: entity-created trigger for scene panel focus -> suggest "Show character panel alongside"
  3. `story-setup-complete`: sequence trigger (3 compose intents within 60s) -> suggest "Create story beats for your acts"
  4. `idle-empty-workspace`: idle trigger (30s, condition: workspace has <2 panels) -> suggest "Get started: open a story setup panel"

Create `src/agents/ambient-observer.ts`:
- `AmbientObserver` interface: `{ dismiss(suggestionId: string): void; getActiveSuggestions(): ActiveSuggestion[]; destroy(): void }`
- `ActiveSuggestion` type: `{ id: string; patternId: string; text: string; intentToDispatch: { type: IntentType; payload: unknown }; createdAt: number }`
- `createAmbientObserver(intentBus: IntentBus, patterns: WorkflowPattern[], onSuggestion: (s: ActiveSuggestion) => void): AmbientObserver`
- Internal state: `recentEvents: IntentEvent[]` (sliding window), `cooldowns: Map<string, number>`, `activeSuggestions: ActiveSuggestion[]`, idle timer (setTimeout)
- On each IntentBus event: check entity-created and sequence triggers. Reset idle timer.
- Idle timer fires after pattern's afterMs with no events.
- Max 2 active suggestions enforced. Per-pattern cooldown enforced.
- 8-second debounce on event processing to batch rapid actions (per user decision: 5-10s).

Write tests first using mock IntentBus and fake timers.
  </action>

  </verify>
