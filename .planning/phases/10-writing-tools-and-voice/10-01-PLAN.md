<task type="auto">
  <name>Task 2: AI writing API route</name>
  <files>src/app/api/ai/writing/route.ts</files>
  <action>
Create `src/app/api/ai/writing/route.ts` as POST endpoint:

Request body: `{ projectId: string, sceneId: string, tool: WritingToolType, selectedText: string, selectionFrom: number, selectionTo: number, options?: { length?: ContinueLength } }`

Implementation:
1. Validate request body (tool must be valid WritingToolType, projectId and sceneId required)
2. Call `assembleStoryContext(projectId, sceneId, selectionFrom, selectionTo)` to gather full story context
3. Call `formatStoryContextForPrompt(ctx)` to build the context section
4. Call `getSystemPrompt(tool, options)` to get the tool-specific system prompt
5. Use Anthropic SDK (`@anthropic-ai/sdk`) to call Claude:
   - system: combined story context + tool prompt
   - user message: the selectedText (or for 'continue', the currentSceneTextBefore ending to continue from)
   - model: 'claude-sonnet-4-20250514' (or whatever model is standard in project)
   - max_tokens: 4096 for continue/expand, 2048 for rewrite/showDontTell/sensoryRewrite
6. Return `NextResponse.json({ result: generatedText, tool, originalText: selectedText })`
7. On error, return 500 with `{ error: message }`

Use `process.env.ANTHROPIC_API_KEY` for authentication (same pattern as existing AI routes).
For the 'continue' tool specifically: the user message should be the text leading up to the cursor position (currentSceneTextBefore + selectedText if any), and the result is NEW text to append. For all other tools, the user message is the selectedText and the result replaces it.
  </action>
