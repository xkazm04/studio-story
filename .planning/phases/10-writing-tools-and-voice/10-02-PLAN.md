    - parseScreenplayToScriptLines given TipTap JSON with characterCue+dialogue nodes returns ScriptLine[] with correct character names and voice IDs from the voice map
    - Action/paragraph nodes map to NARRATOR with narrator voice ID
    - Characters not in voice map fall back to narrator voice ID with a warning flag
    - Audio stitcher accepts array of {audioUrl, gapAfterMs} and returns concatenated Buffer
    - GAP_SAME_CHARACTER = 500ms, GAP_CHAR_CHANGE = 1500ms constants exported
  </behavior>
  <action>
Create `src/app/features/voice/lib/screenplayParser.ts`:
- Export `parseScreenplayToScriptLines(tiptapJson: JSONContent, characterVoiceMap: Record<string, string>, narratorVoiceId: string): ScriptLine[]`
- Iterate through tiptapJson.content nodes. On `characterCue` node, extract text as current character name (uppercase). On `dialogue` node with active character, create ScriptLine with character name and voice from map (fallback to narrator). On `action` or `paragraph` nodes, create ScriptLine with character='NARRATOR' and narratorVoiceId. On `sceneHeading`, skip (not narrated).
- Export helper `extractText(node: JSONContent): string` to recursively extract text from TipTap node.
- Export `detectUnassignedVoices(tiptapJson: JSONContent, characterVoiceMap: Record<string, string>): string[]` that returns character names appearing in cues but missing from the voice map.

Create `src/app/features/voice/lib/audioStitcher.ts`:
- Export `GAP_SAME_CHARACTER = 500` and `GAP_CHAR_CHANGE = 1500` (milliseconds)
- Export `stitchAudioSegments(segments: Array<{ audioBuffer: ArrayBuffer; gapAfterMs: number }>): ArrayBuffer` that concatenates MP3 buffers with silence gaps. Generate silence as zero-filled MP3 frames (128kbps MP3 at 44100Hz: ~16KB per second of silence, so gapMs/1000 * 16384 bytes of zero padding).
- Export `computeGaps(lines: ScriptLine[]): number[]` that returns gap duration after each line: GAP_SAME_CHARACTER if next line has same character, GAP_CHAR_CHANGE if different character, 0 for last line.

Create tests in `src/app/features/voice/__tests__/screenplayParser.test.ts`:
- Test: characterCue followed by dialogue produces ScriptLine with correct character and voiceId
- Test: action node produces NARRATOR ScriptLine
- Test: missing voice in map falls back to narrator voiceId
- Test: detectUnassignedVoices returns characters not in map
- Test: computeGaps returns correct gap values for same/different character transitions
  </action>

<task type="auto">
  <name>Task 2: ElevenLabs API routes (TTS, clone, voices)</name>
  <files>src/app/api/ai/audio/tts/route.ts, src/app/api/ai/audio/clone-voice/route.ts, src/app/api/ai/audio/voices/route.ts</files>
  <action>
Create `src/app/api/ai/audio/tts/route.ts` (POST):
- Body: `{ text: string, voice_id: string, voice_settings?: Partial<VoiceSettings>, model_id?: string, project_id?: string }`
- Call ElevenLabs: `POST https://api.elevenlabs.io/v1/text-to-speech/${voice_id}?output_format=mp3_44100_128`
- Headers: `xi-api-key` from `process.env.ELEVENLABS_API_KEY`, Content-Type: application/json
- Body: `{ text, model_id: model_id ?? 'eleven_multilingual_v2', voice_settings: { stability: 0.5, similarity_boost: 0.75, style: 0.5, use_speaker_boost: true, ...voice_settings } }`
- Response is raw audio bytes (arrayBuffer)
- Upload to Supabase Storage bucket 'audio' with path `narration/${project_id ?? 'misc'}/${Date.now()}-${voice_id}.mp3`
- Return `{ audioUrl: publicUrl, duration: estimatedDuration }` (estimate duration from byte size: bytes / (128000/8) seconds for 128kbps MP3)
- On ElevenLabs error, return 502 with `{ error: 'TTS generation failed', details }`

Create `src/app/api/ai/audio/clone-voice/route.ts` (POST):
- Body: `{ name: string, audioUrl: string, description?: string }`
- Fetch the audio file from audioUrl into a Buffer
- Call ElevenLabs: `POST https://api.elevenlabs.io/v1/voices/add` with multipart/form-data:
  - `name`: voice name
  - `files`: audio buffer as file attachment
  - `description`: optional description
- Return `{ voice_id: response.voice_id, name }`
- On error, return 502

Create `src/app/api/ai/audio/voices/route.ts` (GET):
- Call ElevenLabs: `GET https://api.elevenlabs.io/v1/voices`
- Filter voices to include both user's cloned voices and a curated subset of preset voices (filter by `category === 'premade'` or `labels.use_case` containing 'narration' or 'characters')
- Return `{ voices: Array<{ voice_id, name, category, labels, preview_url }> }`
- Cache response headers: `Cache-Control: public, max-age=300` (5 min cache for voice list)

All routes use `process.env.ELEVENLABS_API_KEY`. Follow same error handling pattern as existing AI routes.
