<objective>
Streaming controller for progressive LLM response rendering

Purpose: Build the streaming infrastructure that enables progressive panel reveal and typewriter text rendering. Patches arrive one-by-one from any transport and are applied immediately for real-time UI updates. On commit, all streamed patches become a single undo group. On abort (user presses Stop), whatever has been rendered stays.

Output: A transport-agnostic StreamController within @dzin/core that processes JSON Patch streams progressively, integrates with the state engine's undo system, and supports abort/commit lifecycle.
</objective>
